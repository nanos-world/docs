## 🎃 Halloween Game Jam is Running! {/* #halloween-game-jam-is-running */}

The **Halloween Game Jam 2026** is officially live, and submissions are open right now! 👇

![](/img/blog/2026-september/game-jam.webp)

<MediaLegend>Halloween Game Jam 2026 page</MediaLegend>

We already have several **submissions**, and there is still plenty of time to join! These are the dates:

- **Submissions & Development Time:** until **October 23**.
- **Public Playtest & Voting:** from **October 30** to **November 1**, open to everyone on Steam.

## Introducing... Projects! {/* #introducing-projects */}

The biggest addition to the website this month: **[Projects](https://nanos-world.com/community/projects)**!

![](/img/blog/2026-september/projects.webp)

<MediaLegend>New Projects page</MediaLegend>

A project is the page for something your team is building or running: a **server**, a **community**, a **tool** or any other creation. It shows people what it is, how far along it is and where to find it, and lets you link the store resources it uses.

Every Team can now create Projects and show them to the world, with their own page, description, screenshots, videos, links and languages.

![](/img/blog/2026-september/project-page.webp)

<MediaLegend>Project page</MediaLegend>

Each Project shows its development **status** (concept, in dev, alpha, beta or released) and how long it has been in development, and has its own **Favorites** count, so people can show their support for it.

Is your project looking for people? Mark it as **Recruiting**, and other developers will be able to find it with the filter on the Projects page!

Go ahead and create your own Project, and show the world what you are working on!

<ReferenceLink href="https://nanos-world.com/community/projects">Community Projects</ReferenceLink>

## Steam App Parameter {/* #steam-app-parameter */}

:::warning

**Attention server owners:** Game Servers now start in the **Playtest** Steam App by default. To run your server for the main "game" app, launch it with the new `--steam_app "game"` parameter. The old `--playtest` parameter was deprecated in favor of `--steam_app "playtest"`.

## WebUI Rendering Rewrite {/* #webui-rendering-rewrite */}

The **WebUI (CEF)** accelerated painting was rewritten using a new shared texture approach, fixing several bugs and improving performance.

We also fixed CEF picking the wrong GPU on laptops with dual GPUs, and a crash when closing the game while a WebUI was playing sounds.


## Scripting Improvements {/* #scripting-improvements */}

### Character Shooter Mode {/* #character-shooter-mode */}

We added a new **Shooter Mode** for Characters with <MethodReference type="Class" class_name="Character" method_name="SetWeaponShooterMode" show_class_name />. In Shooter Mode, a held Weapon stays aimed while idle or walking, it is lowered while sprinting, and the aim input aims down sights instead of raising the Weapon.

```lua title="Server/Index.lua" showLineNumbers
local character = Character(Vector(0, 0, 100), Rotator(), "nanos-world::SK_Male")
character:SetWeaponShooterMode(true)
```


### Client.GetSettings() {/* #clientgetsettings */}

New <MethodReference type="StaticClass" class_name="Client" method_name="GetSettings" show_class_name />, which returns the local player's game settings (toggle sprint/crouch/aim, mouse sensitivity, volumes, etc.), so your UI and game-modes can adapt to them.

```lua title="Client/Index.lua" showLineNumbers
local settings = Client.GetSettings()
Console.Log("Mouse Sensitivity: " .. settings.MouseSensitivity)
```


### GetSocketTransform() {/* #getsockettransform */}

<MethodReference type="Class" class_name="Actor" method_name="GetSocketTransform" show_class_name /> now supports Attachable IDs and also returns the socket's `Scale`.


### Sync Improvements {/* #sync-improvements */}

- <MethodReference type="Class" class_name="Actor" method_name="TranslateTo" show_class_name /> now uses implied velocity when applying synced positions, fixing sync stutters.
- Several improvements to the *experimental* **Based Sync** system from last month, including fixing CharacterSimple entering the falling state when standing on moving platforms, and characters taking ragdoll damage when standing on a moving object.


### Ultra Dynamic Sky Mounting {/* #ultra-dynamic-sky-mounting */}

Servers can now mount their own **Ultra Dynamic Sky** Asset Pack version. If none is mounted, the native one is used when spawning the <StaticClasses.Sky />.


### Other Fixes {/* #other-fixes */}

- Fixed <MethodReference type="Class" class_name="Entity" method_name="CallRemoteEvent" show_class_name /> and <MethodReference type="Class" class_name="Entity" method_name="BroadcastRemoteEvent" show_class_name /> always sending as reliable, regardless of the call's parameters.
- Fixed <MethodReference type="Class" class_name="Vehicle" method_name="SetCameraOffset" show_class_name /> not being applied to the live camera.
- Fixed <MethodReference type="StaticClass" class_name="Sky" method_name="SetOverallIntensity" show_class_name /> not working correctly.
- Fixed `Character:SetCameraMode(FPSOnly)` attaching the camera on the character's feet.
- Fixed loading cooked textures (e.g. from `SetMaterialTextureParameter()`) not working if they weren't loaded before.
- Fixed lean **Asset Packs** not being sent to clients.
- Fixed file transfers showing PB/TB/s download speeds after the first transfer.
- Fixed the `--max_tick_rate`, `--max_sync_rate`, `--max_send_rate` and `--max_file_transfer_rate` server parameters not being parsed correctly.
- Fixed menu crashes when downloading images.


### Dependencies Updated {/* #dependencies-updated */}

- Updated **Steam SDK** to v1.65.

## Conclusion {/* #conclusion */}

September was all about the website and getting everything ready for the Halloween Game Jam. With **Projects**, the **Hub**, **Support** and the new Profiles, the website is becoming the real home of the nanos world community, and not only a place to download stuff.

This whole website overhaul is part of my goal of having a fully integrated community ecosystem (one of the items in our Roadmap). I truly believe that having a welcoming and collaborative environment for the community is the most important part of nanos world, and I want to make sure that everyone can find their place in it, and that everyone can contribute to it in a meaningful way. I still have big plans for our community, and I hope to keep improving it in the coming months.
