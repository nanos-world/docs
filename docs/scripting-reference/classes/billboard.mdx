## 🎒 Examples {/* #examples */}

```lua title="Client/Index.lua" showLineNumbers
local my_billboard = Billboard(
    Vector(200, 200, 200), -- location
    "nanos-world::M_Default_Masked_Lit", -- material
    Vector2D(32, 48), -- size: half width (X) and half height (Y)
    true
)

my_billboard:SetMaterialTextureParameter("Texture", "package://my_package/Client/image.jpg")
```

:::caution

Since **1.166.0**, `size.X` is the width and `size.Y` the height. Before that they were swapped, so if you worked around it by passing `Vector2D(height, width)`, swap them back.

Both values are half sizes: `Vector2D(32, 48)` renders 64 wide and 96 high.

:::
