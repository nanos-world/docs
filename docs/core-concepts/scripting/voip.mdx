How VOIP works in nanos world and how to use it.

nanos world provides a built-in Voice over IP (VOIP) system using Steam's native implementation that allows players to communicate with each other in-game through voice. The VOIP system is highly customizable and can be configured to use local/proximity chat, global channels, or both.


## VOIP Audio Types {/* #voip-audio-types */}

The VOIP system is based on two main types: **local/proximity** and **global**.


### Local/Proximity {/* #localproximity */}

Local VOIP uses a 3D spatialized audio to output the Player's voice. Usually this is attached to the possessing Player's Character and simulates a realistic audio environment where players can only hear each other if they are close by.

You can enable or disable local chat for a player using <MethodReference type="Class" class_name="Player" method_name="SetVOIPLocalSetting" show_class_name />. The volume of the local chat can be adjusted with <MethodReference type="Class" class_name="Player" method_name="SetVOIPLocalVolume" show_class_name />, and how far the voice can be heard with <MethodReference type="Class" class_name="Player" method_name="SetVOIPLocalMaxDistance" show_class_name />.


### Global {/* #global */}

Global VOIP allows players to communicate with each other regardless of their location in the game world. There are 63 global channels available (1-63). Players can be configured to listen or speak on specific channels.

You can configure a player's settings for a specific global channel using <MethodReference type="Class" class_name="Player" method_name="SetVOIPGlobalChannelSetting" show_class_name /> or for all channels at once with <MethodReference type="Class" class_name="Player" method_name="SetVOIPGlobalAllChannelsSetting" show_class_name />. Also the volume of the global chat can be adjusted with <MethodReference type="Class" class_name="Player" method_name="SetVOIPGlobalVolume" show_class_name />.

You can check in which channels a player is listening or speaking with <MethodReference type="Class" class_name="Player" method_name="GetVOIPListeningChannels" show_class_name /> and <MethodReference type="Class" class_name="Player" method_name="GetVOIPSpeakingChannels" show_class_name />.

```lua title="Server/Index.lua" showLineNumbers
-- Creates a "team radio": players of each team speak and listen only in their team channel
function SetPlayerTeamRadio(player, team)
    -- Stops listening and speaking in all global channels
    player:SetVOIPGlobalAllChannelsSetting(VOIPSetting.None)

    -- Speaks and listens in the team channel (team 1 uses channel 1, and so on)
    player:SetVOIPGlobalChannelSetting(team, VOIPSetting.Both)
end
```


## High/Low Pass filters {/* #highlow-pass-filters */}

In the Global Channels, it is possible to set filters on the Global audio with the methods <MethodReference type="Class" class_name="Player" method_name="SetVOIPGlobalHighPassFilter" show_class_name /> and <MethodReference type="Class" class_name="Player" method_name="SetVOIPGlobalLowPassFilter" show_class_name />.

We can simulate a **Radio Effect** by setting a High Pass filter like `player:SetVOIPGlobalHighPassFilter(8000)`.

:::note

High/Low Pass filters are only available in the Global Channels.

:::


## VOIP Settings {/* #voip-settings */}

The VOIP settings for both local and global channels are configured using the <Enums>VOIPSetting</Enums> enum. It is possible to define if the player will just listen, speak or both, on the local channel and on each global channel!


## Knowing Who is Talking {/* #knowing-who-is-talking */}

The <EventReference type="Class" class_name="Player" event="VOIP" /> event is triggered when a player starts or stops talking, which is useful to display a "talking" indicator in your UI:

```lua title="Client/Index.lua" showLineNumbers
Player.Subscribe("VOIP", function(player, is_talking)
    Console.Log("%s is %s", player:GetName(), is_talking and "talking" or "silent")
end)
```


## Muting {/* #muting */}

It is possible to mute a certain player using the <MethodReference type="Class" class_name="Player" method_name="SetVOIPMuted" show_class_name /> method. If this is called on Server side, the Player will be muted for everyone, but it can also be called on client side for a local mute.


## Configuring Microphone {/* #configuring-microphone */}

As we use Steam implementation, you can configure your microphone in the Steam's settings, which can be accessed through the Steam client or Shift+Tab Overlay. This allows you to adjust your microphone volume, test your microphone, and set other audio preferences.
