## 🚀 Start Here {/* #start-here */}

New to nanos world scripting? Follow these in order, each one builds on the previous:

1. [Essential Concepts](/getting-started/essential-concepts.mdx): how everything works
2. [Quick Start](/getting-started/quick-start.mdx): start your server and create your first Package
3. [Your First Game-Mode](/getting-started/your-first-game-mode.mdx): build a small deathmatch, with a HUD and remote events
4. [Name Tags](/getting-started/tutorials-and-examples/name-tags.mdx) and [Doors](/getting-started/tutorials-and-examples/doors.mdx): short examples using events and triggers
5. [Basic HUD (Canvas)](/getting-started/tutorials-and-examples/basic-hud-canvas.mdx): track the local Character and draw a HUD
